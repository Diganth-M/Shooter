# 🎯 SHOOTER — NIGHT RANGE

A responsive browser arcade shooter where you aim and shoot airborne bottles, birds, and clay plates. Clear each round before your bullets run out.

## Features
- Seven progressive rounds with a gentler opening and increasing difficulty
- Limited bullets, accuracy bonuses, and combo scoring
- Airborne bottle, bird, and clay plate targets
- Moving targets and a visible thrower
- Mouse, touch, and pointer controls
- Recoil, shot trails, hit particles, and sound effects
- Persistent best score with localStorage
- No external assets or backend required
- GitHub Pages ready

## Controls
- Move mouse / finger: aim
- Click / tap: fire
- Pause button: pause the round
- Sound button: toggle sound
- Restart: return to Round 1

## Run locally
Open `index.html` in a modern browser, or publish the repository with GitHub Pages.
