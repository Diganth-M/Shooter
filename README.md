# 🏹 ARCHERY — Precision Range

A responsive browser archery challenge where players draw a bow, manage pull force, and release arrows to hit rotating bottles and clay targets arranged in a straight line.

## Features
- Hold and release bow controls with mouse, touch, and pointer input
- Live draw-force meter with pull-speed feedback
- Precision scoring that rewards strong, fast draws and accurate hits
- Rotating straight-line target formations
- Limited arrows and a bonus for conserving arrows
- Seven progressive rounds with gradually increasing difficulty
- Hit particles, bow animation, sound effects, and pause controls
- Persistent personal-best score with localStorage
- No backend required; GitHub Pages ready

## Controls
- Hold mouse button or touch the range to draw the bow
- Move the pointer while holding to aim
- Release to launch an arrow
- Ⅱ: pause · ♫: sound · RESTART RUN: start again

## Scoring
Points increase with draw force, pull speed, shot accuracy, and combo streaks. Clearing a round with more arrows remaining adds a conservation bonus.
